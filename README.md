# 记忆书架 · Memory Palace

每一本书是一座可以飞进去的三维记忆宫殿：书的结构变成街区和路线，关键情节变成只属于它的物件。

在线访问：https://chensher.github.io/memory-palace/

## 已上架

- 《股票作手回忆录》：七个街区、35 站，K 线按书中原文价位绘制 → `books/reminiscences-of-a-stock-operator/`
- 《缠论》：暂时链接到 chern_capital 的阅读页

## 新书上架

1. 在 `index.html` 的 `BOOKS` 列表加一项；
2. 把宫殿放进 `books/<书名>/index.html`（单文件，three.js 从 cdnjs 加载）。
